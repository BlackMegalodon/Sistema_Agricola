# Sistema_Agricola

Este é um aplicativo de documentação de Visitas Técnicas Agrícolas, para utiliza-lo será necessario o EXPO GO no seu dispositivo movel.

Primeiro Passo:
Abre seu CMD no seu computador e selecione a pasta do sistema com CD Sistema_Agricola

Segundo Passo:
Use "NPM Install" para instalar e baixar componentes necessarios (Está etapa pode ser pulada uma vez que feita pela primeira vez)

Terceiro Passo:
Utilize "NPX expo start" para iniciar o projeto

Quarto Passo:
Abre seu Expo Go e escaneie o código QR oferecido pelo CMD
